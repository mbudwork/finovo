# Заявки с сайта → Google-таблица + Telegram

Форма на сайте отправляет заявку в два места:
1. **Netlify Forms** (основная копия: Netlify → проект → Forms → `kontakt`);
2. **Google Apps Script** (`apps-script.gs`) → строка в таблице «Заявки» + сообщение боту в Telegram.

## Подключение
1. Новая Google-таблица → Расширения → Apps Script → вставить `apps-script.gs`.
2. Вписать `TG_TOKEN` и `TG_CHAT_ID` **только в редакторе Apps Script** (репозиторий публичный — в git токен не класть).
3. Запустить `testTelegram` один раз (Google попросит разрешения) — в Telegram придёт тестовая заявка.
4. Развернуть → Новое развёртывание → тип «Веб-приложение»: выполнять от имени «Меня», доступ «Все».
5. Скопировать адрес `https://script.google.com/macros/s/…/exec` в `LEADS_HOOK` в `site/build.py` и закоммитить.

Если скрипт поменяли — «Управление развёртываниями» → изменить → новая версия (адрес остаётся тем же).

# Finovo — кабинет (исходники)

> Сейчас кабинет собирается вместе с сайтом: `python3 build.py` в корне репозитория кладёт его в `dist/app/`. См. README в корне.

Один исходник — две сборки:

- `out/kabinet/` — настоящий кабинет для Netlify (база Supabase, push-уведомления, вход клиентов и бюро);
- `out/demo.html` — демо для сайта, кладётся в сайт как `src/demo/index.html`.

Сборка: `python3 make_app.py`.

## Файлы

- `app.html` — приложение (кабинет клиента и пульт бюро). Тексты в коде на русском, это «ключи» перевода.
- `dict.py` — словарь переводов на польский и украинский. Новый текст в приложении = новая строка здесь.
- `make_app.py` — сборщик: добавляет перевод, выбор языка, убирает демо-данные из настоящей версии.
- `kabinet-static/` — service worker (push), манифест, иконки Finovo, заголовки Netlify (noindex).
- `functions/notify/` — серверная функция Supabase: напоминания о сроках, документах, должниках,
  закрытии месяца. Тексты на языке пользователя. Уже выложена в Supabase (версия 2).

## Язык

- Пользователь выбирает PL / UA на экране входа и в меню.
- Выбор хранится в браузере и в базе (`notify_prefs.lang`), по нему сервер пишет push и e-mail.
- По умолчанию: украинский для браузеров на украинском или русском, иначе польский.

## Адрес кабинета

Когда кабинет переедет на app.finovo.com.pl, в базе нужно указать адрес для ссылок в письмах:
`app_url` в настройках (секретах) приложения. До этого ссылки ведут на kabinet-biuro.netlify.app.
